The SDK is open source — it's how you build the conversational experience.

1. Define your state


export const skiLessonsFlow = createFlow({
  id: "ski_lessons",
  title: "Book a Ski Lesson",
  state: {
    level: z.enum(["beginner", "intermediate", "advanced", "expert"])
      .describe("Infer from context: 'I ski blacks' → advanced"),
    groupSize: z.number().int().min(1).max(12)
      .describe("Infer from mentions of family, couples, solo..."),
    date: z.string()
      .describe("Keep it the way the user said it"),
    time: z.enum(["morning", "afternoon"]),
    goals: z.string()
      .describe("What the skier wants to work on"),
    lessonPlan: z.enum(["private", "small_group", "family"]),
  },
})

.describe() strings become extraction hints for the LLM

2. Ask naturally with interrupt


.addNode("welcome", ({ interrupt }) => {
  return interrupt({
    goals: {
      question: "Tell me about your ski trip!",
      context: `Greet warmly. Ask ONE open-ended question.
        Extract whatever they naturally share into state.`
    },
  });
})

.addNode("gather_details", ({ state, interrupt }) => {
  return interrupt({
    // Only asks for what's still missing
    ...(!state.level   ? { level:     { question: "What level?" } } : {}),
    ...(!state.date    ? { date:      { question: "What day?"   } } : {}),
    ...(!state.groupSize ? { groupSize: { question: "How many?"  } } : {}),
  });
})

Conversational, not a form. Skips what's already known.

3. Show rich UI with showWidget


.addNode("show_lesson_plans", ({ state, showWidget }) => {
  const plans = buildPlans(state.groupSize, state.level);

  return showWidget("select-lesson-plan", {
    field: "lessonPlan",
    data: {
      level: state.level,
      groupSize: state.groupSize,
      date: state.date,
      plans,
    },
  });
})

User taps a card → choice flows back into state automatically

4. Wire it up


  .addEdge(START, "welcome")
  .addEdge("welcome", "gather_details")
  .addEdge("gather_details", "show_lesson_plans")
  .addEdge("show_lesson_plans", "confirm_booking")
  .addEdge("confirm_booking", END)
  .compile();

Reads like a flow diagram — because it is one.

.compile() turns it into a single MCP tool

Connect to the platform


server.registerTool(
  skiLessonsFlow.name,
  skiLessonsFlow.config,
  skiLessonsFlow.handler,
);

withWaniwani(server, { client: waniwani() });

server.run();
